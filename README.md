# Python Calculator 🧮

A beginner-friendly command-line calculator built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Menu-driven interface
- Input validation
- Division-by-zero handling

## Concepts Practiced

- Functions and return values
- `while` loops
- `if`, `elif`, and `else`
- User input
- Exception handling

## How to Run

Make sure Python 3 is installed.

```bash
python calculator.py
```

Follow the menu instructions to perform calculations or exit.

## What I Learned

This project helped me practice breaking a program into reusable functions and handling user input through a menu-driven interface.

More improvements will be added as I continue learning Python.
